# Skill: validar comando de fabricante

1. Registrar fabricante, produto, família, versão e modo operacional.
2. Localizar referência oficial do comando.
3. Testar em laboratório compatível quando possível.
4. Salvar comando, pré-condições, saída sanitizada e resultado.
5. Marcar como `documentado`, `testado`, `ambos` ou `não validado`.
6. Nunca usar comando de outra plataforma por analogia.
